# Anki 知识点：发音与听力

> [[anki知识点]] 的听力、发音和高频表达整理版。听力材料中的词汇只收录“会影响理解或输出”的内容。

## 易混元音：`/e/`、`/æ/`、`/ʌ/`

| 音标 | 发音提示 | 对比词 |
| --- | --- | --- |
| `/e/` | 嘴角略向两边，张口小、短促 | bed, pen, desk, head |
| `/æ/` | 张口更大，下巴更低 | bad, pan, map, bag |
| `/ʌ/` | 舌位较后，短促放松 | bud, fun, cup, bus |

### 30 秒对比练习

录音读三组，再回听区分是否清楚：

```text
bed / bad / bud
pen / pan / pun
said / sad / suds
```

不是把中文音拉长，而是保证三个元音的口型差异。每次只练一组，连续读三遍即可。

## 常见发音与拼写提醒

| 词 | 提醒 |
| --- | --- |
| climb | `b` 不发音：/klaɪm/ |
| separate | 动词 /ˈsepəreɪt/；形容词 /ˈsepərət/ |
| theatre / theater | theatre 为英式拼写；theater 为美式拼写 |
| honour / honor | honour 为英式拼写；honor 为美式拼写 |
| breath / breathe | breath 是名词 /breθ/；breathe 是动词 /briːð/ |
| advice / advise | advice /s/ 为名词；advise /z/ 为动词 |
| close | 动词 /kloʊz/；形容词 /kloʊs/ |

## 听力高频时间与动作表达

| 表达 | 含义 | 例句 |
| --- | --- | --- |
| a quarter to seven | 六点四十五分 | We set out at a quarter to seven. |
| set out for ... | 出发前往…… | We set out for the Modern Farm. |
| stay up late | 熬夜 | I stayed up too late last night. |
| first of all | 首先 | First of all, thank you for coming. |
| all in all | 总之 | All in all, it was a good day. |
| just as ... | 正当……时 | Just as he was about to cry, she arrived. |

### 易错修正

| 原意 | 推荐表达 | 说明 |
| --- | --- | --- |
| 我昨晚熬得很晚 | I stayed up too late last night. | 用 `too`，不是 `to`。 |
| 实践的 | hands-on | 形容词需连字符。 |
| 卖完了 | be sold out | `sell out` 表示库存售罄。 |
| 微笑传播善意 | Smiles spread kindness. | `kindness` 比 `the message` 更贴合原意。 |
| 在学习时兼职 | find a part-time job while studying there | `part-time` 作形容词需连字符。 |
